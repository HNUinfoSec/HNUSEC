刚到湖大时，课怎么选、电脑怎么配、消息去哪里找，常常都要问上一圈。我们想把这些亲身经历慢慢整理下来，让下一届同学少一些无从下手的时刻。

这份指南正在一起编写。现在先把选题和入口搭好，接下来欢迎大家带着自己的故事来补充：一门课的学习方法、一次环境配置的踩坑，或者一个当初希望有人早点告诉你的提醒，都可以写。

## 我们准备写些什么

下面是第一批想征集的话题。它们还没有独立文章，也欢迎你提出其他选题。

| 话题 | 可以从这些问题写起 |
| --- | --- |
| 入学与校园日常 | 刚来时哪些事情最容易弄不清？你会把哪些校园入口留在收藏夹里？ |
| 课程与学习 | 某门课需要怎样的基础？实验怎么准备？哪些学习习惯对你有帮助？ |
| 电脑与开发环境 | 自己的设备能否完成课程实验？Windows、WSL、Linux、macOS 分别踩过哪些坑？ |
| 项目、竞赛与方向探索 | 你怎样找到第一个项目或队友？参加一次比赛前，需要做哪些准备？ |
| 大学生活与选择 | 怎样安排学习和休息？遇到困难时，你从哪里得到过帮助？ |

我们尤其想读到发生在湖大的具体经历。比如“我在某门课里怎样配置环境”，就很适合写成一篇短文。

## 先收藏几个校园入口

| 入口 | 可以在这里找什么 |
| --- | --- |
| [湖南大学官网](https://www.hnu.edu.cn/) | 学校通知，以及校内机构和服务的导航 |
| [网络空间安全学院](https://cst.hnu.edu.cn/) | 学院发布的通知与信息 |
| [本科生院](https://jwc.hnu.edu.cn/) | 本科教学相关通知 |
| [个人门户](https://iportal.hnu.edu.cn/) | 学校个人门户入口 |
| [图书馆](https://lib.hnu.edu.cn/) | 图书馆资源与服务入口 |

选课、培养方案、评奖评优等具体安排，记得查看当年的学校和学院通知。文章里的经验也会标明适用时间，方便你判断是否还适合自己的情况。

想先聊聊选题的话，欢迎来 [HNUSEC 交流群](https://qm.qq.com/q/JSaru1wB4C)（**571381107**）。
