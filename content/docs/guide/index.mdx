欢迎各位来到湖南大学网络空间安全学院。

此 wiki 是借着 2025 CTF 新生杯建立的。目的在于为刚进入大学的各位提供一些思路与建议。

## 认识 HNUSEC

HNUSEC 是湖南大学信息安全协会。无论你已经有感兴趣的方向，还是刚开始接触计算机与网络安全，都欢迎来和大家交流。

- **关注 GitHub 组织**：访问 [HNUinfoSec](https://github.com/HNUinfoSec)，点击 **Follow** 关注我们，也可以浏览组织中的项目，为感兴趣的仓库点一个 Star。
- **加入交流群**：点击 [加入协会 QQ 群](https://qm.qq.com/q/JSaru1wB4C)，或在 QQ 中搜索群号 **571381107**（2026HNUSec迎新群），和同学们交流学习、关注活动公告。
- **一起完善官网**：发现错别字、失效链接，或想分享自己的学习经验，欢迎到 [官网仓库](https://github.com/HNUinfoSec/HNUSEC) 提 Issue 或 Pull Request。

## 从哪里开始

- 想找在湖大学习与生活的经验？看看正在共建的 [HNU 生存指南](/docs/survival)，也欢迎写下自己的故事。
- 想了解网络安全和 CTF？先看 [CTF 入门](/docs/security/start)，认识不同方向。
- 想安排自己的计算机学习？看看 [CS 学习](/docs/CS-study) 中的自学资源。
- 想听听过来人的建议？读读 [SkyWT 学长的经验分享](/docs/words/SkyWT)，也可以逛逛 [同学们的博客](/friends)。
